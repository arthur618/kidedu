# C2 孩子端界面（认字回路）

- 交给：Codex
- 批次：第二批，需要 C1 和 D1 已合并到 `main`
- 分支：`task/C2`
- 允许修改的路径：`app/(child)/`、`src/ui/`

## 目标

做出孩子用的界面，覆盖认字回路的全部屏幕。使用者是 8–10 岁的孩子，在平板或手机上用，没有大人在旁边教。

## 要读的

- `src/contracts/orchestrator.ts`：`SessionState` 的每个值对应一个屏幕；`Effect` 里的 `show` 告诉界面显示哪个屏幕。
- `src/contracts/schemas.ts`：`HomeworkItem`、`CharCard`、`DictationMark`、对话类输出的 `say` / `ask`。
- D1 交付的 `src/server/README.md`：接口地址和用法。

## 屏幕

| 状态 | 屏幕上有什么 | 孩子做什么 |
| --- | --- | --- |
| homework_capture | 一个大的拍照按钮，一个“我来说”按钮（先做成文字输入） | 拍下或输入今天的作业 |
| homework_confirm | 作业清单，每项可以删、可以改 | 点“对的，开始” |
| recognize | 一次一个词，要认的字高亮 | 点“认识”或“不认识”（self_report 模式） |
| understand | 字卡：大字、拼音、小问号的讲解（`say`）、请孩子做的事（`ask`） | 输入一个词或一句话 |
| dictation_play | 播放按钮、“再听一遍”、进度（第几个，共几个） | 在纸上写，点“下一个” |
| dictation_capture | 拍照按钮 | 拍下写的字 |
| dictation_compare | 每个字：孩子写的（从照片里裁出来）和标准字并排；可疑的字有标记 | 逐个点“一样”或“不一样” |
| reading_offer | “今天有个小故事，要读吗？”两个按钮 | 选 |
| wrap_up | 今天学会了哪些字、哪些字过几天再见；三个表情 | 点一个表情 |

阅读和作文相关的屏幕本任务只做占位页，显示“即将开放”。

## 设计要求

- 一屏只做一件事，只有一个主要按钮。
- 按钮和可点区域不小于 56 像素见方。正文字号不小于 20 像素，要认的字不小于 96 像素。
- 所有文字是三年级孩子读得懂的简体中文，不出现“提交”“确认”“错误”“加载失败”这类词。用“好了”“对的”“再试一次”。
- 答错不出现红叉和负面的词。用“这个字我们再看看”。
- 没有计时器，没有分数，没有连续打卡。
- 屏幕上始终有一个“今天先到这”的出口，点了发送 `quit`。
- 320 像素宽的手机上不出现横向滚动；平板横屏时内容居中，最大宽度 720 像素。
- 小问号这个角色用一个简单的原创图形表示（比如一个带问号的圆形机器人），不使用任何现有的卡通形象。
- 网络慢或接口失败时，显示“小问号在想，等一下”并可重试，不显示技术信息。
- 支持键盘操作和屏幕阅读器的基本语义（按钮是 `button`，图片有 `alt`）。

## 实现要求

- 界面不自己决定下一步。每次孩子操作后把事件发给服务端，按返回的状态和 `show` 效果渲染。
- 拍照用 `<input type="file" accept="image/*" capture="environment">`，上传前在浏览器里压缩到长边不超过 1600 像素。
- 听写对照里“孩子写的字”用 `DictationMark.box` 从照片里裁；`box` 为 `null` 时显示整张照片并高亮对应的词。
- 界面组件放 `src/ui/`，页面放 `app/(child)/`。组件只接收数据和回调，不直接请求接口，方便测试。

## 验收标准

1. 上表每个屏幕有一个组件，各有渲染测试：给定数据能渲染出关键文字和主要按钮。
2. 一个端到端的流程测试：用假的服务端（按契约返回固定序列），从 homework_capture 点到 wrap_up，每一步发出的事件类型和顺序正确。
3. 接口返回失败时显示重试界面，页面上不出现 `Error`、`undefined`、状态码或英文报错（测试断言）。
4. 所有按钮的可点区域不小于 56 像素（测试里检查样式，或在报告里附说明和截图）。
5. 源码里孩子可见的字符串不包含“提交”“错误”“失败”“确认”（用一个测试扫描 `app/(child)/` 和 `src/ui/`）。
6. 每个屏幕都有“今天先到这”，点击后发出 `quit` 事件。
7. 报告里附每个屏幕在 375×667 和 1024×768 两种尺寸下的截图。
8. `bash scripts/verify.sh C2` 通过。

## 不在范围内

- 不做家长端，不做登录（用 D1 提供的方式拿到孩子编号）。
- 不做语音录入和朗读。
- 不调模型，不写提示词。
- 不改接口。接口不够用就在报告里写明缺什么。
