## 做了什么

提供默认关闭的 `/parent`，只显示服务端授权孩子的公开日报、当前分阶段认字进度、可信归属事件及只读删除范围预览。日报复用 C11A `getDailyReport`，复核公共行的孩子、日期、时区与真实会话归属，不读取 Nightly 私有快照、评分步骤、作文或原始 Turn。

家长登录采用随机 256 bit opaque cookie，数据库只存 hash，24 小时绝对期限、持久限速、同源 JSON 校验，配置指纹变化和退出使旧凭证失效。事件通过真实 Session 同事务保存归属；人工状态变更使用稳定请求 ID、方法/路径/正文指纹、revision CAS，同事务提交状态、审计和响应，同值请求只记指纹。

UI 区分事实与模型参考、0 分与不可用、历史流水覆盖、无日报及未开启入口；切换孩子、筛选、翻页、退出和过期使用取消与世代检查隔离晚到响应。没有模型触发、真实数据删除、字卡终审、排行榜、奖励或真实外部服务配置。

## 正式裁决逐项

1. 两个服务端环境项只有合法非空才启用；示例只加空值。关闭时 status 不查家庭表、其他接口 403。
2. SHA-256 定长摘要恒定时间比较；SQLite 单户登录预算每 15 分钟 8 次，不使用任意代理 IP；实际事务内读取服务端时钟，单条写入 RETURNING 原子取预算，只有严格更新窗口才重置，旧时间不倒拨，超限计数饱和为 9；随机 token 32 bytes，DB 只有 hash；cookie HttpOnly、Strict、API 路径、生产 Secure、24 小时绝对期限；旧凭证配置指纹失效、退出撤销。
3. 登录也检查同源 Origin 与 JSON；鉴权先于家庭查询。child 白名单先于 Child 查询；越权和不存在统一 404。数据响应均 no-store。
4. 只读 NightlyPublication，通过真实模块核对 child/date/timezone，并复核日报引用的真实 Session。当前 counts 全阶段统计，字进度 100、日报/事件 20 条一页；签名游标绑定资源、孩子和筛选，并核对游标真实记录。
5. Incident+Context 同事务，childId 由 Session 取得。已知 effects/reading/essay 及获准 runtime 缺字卡调用仅补 sessionId。无 context 的旧可信 Turn 可推导 Session；无来源、来源矛盾、孤儿记录均隐藏，UI 明确说明历史缺归属。
6. 查询不选事件自由 note 或 Turn 正文，仅固定安全概况与有限元信息；模型标识只接受有限标识字符。React 文本呈现，无外链媒体加载或 HTML 注入。
7. 复核固定 parent actor、服务端时间、前后值与版本；实际变更才审计/revision+1，同值仍记请求指纹；响应与状态、审计、指纹同事务。事务内再次核验当前凭证，稳定 ID 重放与并发 CAS 已回归。
8. 复核不改学习和内容表；UI 提醒字卡仍须检查、复核、人工终审再导入，无模型自动 resolve 能力。
9. 预览与详情共用可信 Session/Turn 事件集合，矛盾或孤儿不计入家庭范围，流水/审计/命令同样核对真实归属。预览覆盖 18 类家庭资料/学习/私有活动/命令/事件/人工审计/日报来源与发布表计数，只读事务、生成时间和指纹、executable=false。UI 说明关联引用、历史缺归属另核对、共享内容与家长凭证另管；没有删除端点或保留期清理。
10. `/parent` 语义 h1/label/按钮和键盘交互；375×667、1024×768 实际浏览器通过。未开启和无日报正常显示，孩子端没有成绩或奖励改动。
