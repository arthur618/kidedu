## 时序与接口

| 孩子动作 | 接口 | 服务端依次做什么 |
| --- | --- | --- |
| 打开学习页 | POST /api/session | 校验ID/正文→按孩子串行→事务内建Session、初始ctx、start转换、命令检查点→事务外组装显示→保存完成响应 |
| 口述/拍作业 | POST /api/session/[id]/homework | 校验图片→读取会话/时限→事务外vision_homework→记录Turn→unsure留capture；否则事务内homework_captured+去图清单检查点→完成响应 |
| 对清单点开始、认读选择 | POST /api/session/[id]/event | 校验共享事件→时限→事务内reduce+学习/会话/ctx+命令检查点→事务外执行显示/Agent/报词→保存完成响应 |
| 听完讲解、组词、说一句话 | POST /api/session/[id]/coach | 检查当前字/活动→事务外真实char_coach+withGuard→下一步实际提示→事务内CoachRuntime+complete；完成活动则事务内understand_done+学习+检查点，再执行下一活动效果 |
| 听完报词、上传听写、逐字对照 | POST /api/session/[id]/event | 报词只读approved卡；照片事件先提交compare检查点再跑vision；失败/看不清保留所有expected marks，box=null、suspicious=true；判断始终由孩子自己点 |
| 下次再读、今天先到这、心情 | POST /api/session/[id]/event | 正常持久转换、收尾与结束；汇总只列当天lastSeenOn的实际学习记录，不把尚未尝试的到期复习字写成今天收获 |
| 刷新或读取进度 | GET /api/session/[id] | 只读当前运行时与已存显示/可信内容；不跑模型、不推进coach；无原图返回photo_not_available |

四个POST都发送 `Idempotency-Key: operation_00000001` 这类合法操作ID。一次操作重试保留同ID；有意再说/拍一次、排队的quit用新ID。正文指纹规范化包含方法、接口和正文的SHA-256；start scope为childId，其他为sessionId。

请求例：

```json
{"childId":"child-test-1","lessonId":"c7-lesson","hasEssayToday":false}
```

```json
{"char":"山","text":"山字"}
```

```json
{"type":"recognize_result","char":"山","result":"correct","mode":"self_report"}
```

```json
{"spokenText":"读一读自编课文的生字"}
```

响应例：

```json
{"sessionId":"session_example","state":"homework_capture","effects":[{"type":"show","screen":"homework_capture"}]}
```

```json
{"sessionId":"session_example","state":"understand","effects":[],"unavailable":{"reason":"missing_content","say":"这张字卡还没准备好，今天先到这吧。"}}
```

```json
{"sessionId":"session_example","state":"ended","effects":[]}
```

GET兼容保留顶层context和homework。缺失/非法操作ID、正文或图片返回400，孩子/课/会话不存在404，教练状态不符或同ID异正文409。业务拒绝保存rejected终态，不阻塞后续命令。

## 事务、重放和预算边界

`SessionCommand` 的 prepared→transitioned→complete 是持久检查点；`CoachRuntime` 不混入SessionContext。学习转换与transitioned在同一短事务，coach步骤/历史与complete在同一短事务。start创建也在事务内，外部效果直到最外层事务真正提交后才执行。D1的handleEvent仍是持久化转换原语，外层runtime负责接线与事务外效果；保留D1完整ctx原样往返与失败回滚测试。

响应丢失后重放读取持久结果；状态已提交但外部效果未完成时，只恢复外部效果/回复，不再次reduce或累计孩子发言。服务重启后新操作先恢复较早检查点。进程崩溃可造成外部模型重新调用，不能承诺模型侧恰好一次；学习转换/coach步骤不会因此重复。仅支持单Node进程同会话串行，未实现多实例锁。

100秒预算只竞速无状态写权限的模型结果，真实fetch合并取消信号；预算耗尽不启动后续模型，正常内容库/Agent兜底继续返回。迟到结果不能推进状态、覆盖退出或补写Turn。预算中止时若上游尚无完成计量，已开始调用仍记录实际路由模型名及本地时钟已知的开始至取消耗时；未知token为0，不声称知道上游实际消费量。onTurn经AsyncLocalStorage与当前调用配对，实际数据库写入明确await，不会被D2/Agent吞异常。存库异常使接口显式失败并留可恢复命令；数据库不可用时不承诺远端调用记录恰好一次。

图片不写Turn、Incident、CoachRuntime、SessionCommand、SessionRuntime、Session或日志。图片命令的待处理效果/缓存只存占位符，完整正文只参与哈希；同ID同正文重试重新提供原图。照片按当前显示及原命令指纹绑定，非法新ID照片不替换旧图；离开对照释放进程内原图。重启后GET正常缺图；原命令重放在当前仍对照时可重新注入图片，必要时重做纯视觉外部效果；退出后只返回合法历史结果，不以当前state重跑旧动作。无原图恢复旧作业命令时请重拍，不让模型凭空造作业。
