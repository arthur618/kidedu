## 讲解和报词全文

以下与JSON卡片一致，可直接逐条指出要改的字。每卡后面的词典链接核对拼音、部首与释义；配套教学资料只用于交叉核字表，不采纳其中错误的笔顺/字源说明。

### 第1课

- [ ] **坡**：坡是左右结构，左边是土，右边是皮。坡是倾斜的地方，山坡是山上倾斜的地面。 报词：坡，山坡的坡。[词典](https://zdic.net/hans/坡)

- [ ] **球**：球是左右结构，左边是王字旁，右边是求。球可以指圆圆的立体物，也可以指球类运动用的东西。 报词：球，气球的球。[词典](https://zdic.net/hans/球)

- [ ] **招**：招是左右结构，左边是提手旁，右边是召。招手是挥动手，向别人示意。 报词：招，招手的招。[词典](https://zdic.net/hans/招)

- [ ] **呼**：呼是左右结构，左边是口，右边是乎。呼有喊叫的意思，也可以表示向外出气。 报词：呼，呼喊的呼。[词典](https://zdic.net/hans/呼)

- [ ] **飘**：飘是左右结构，左边是票，右边是风。飘表示随风飞动。 报词：飘，飘扬的飘。[词典](https://zdic.net/hans/飘)

- [ ] **扬**：扬是左右结构，左边是提手旁。扬有举起的意思，扬手就是举起手。 报词：扬，飘扬的扬。[词典](https://zdic.net/hans/扬)

- [ ] **读**：读是左右结构，左边是言字旁，右边是卖。这课的“读”读dú，表示看着文字念出来。 报词：读，读书的读。[词典](https://zdic.net/hans/读)

- [ ] **热**：热是上下结构，下边是四点底。热表示温度高，和冷相对。 报词：热，热水的热。[词典](https://zdic.net/hans/热)

- [ ] **闹**：闹是半包围结构，门里面是市。闹可以表示不安静，热闹是人多、声音多的样子。 报词：闹，热闹的闹。[词典](https://zdic.net/hans/闹)

- [ ] **粗**：粗是左右结构，左边是米，右边是且。粗可以形容长条东西的横截面大，和细相对。 报词：粗，粗壮的粗。[词典](https://zdic.net/hans/粗)

- [ ] **壮**：壮是左右结构，右边是士，士的上横比下横长。壮有强健、有力的意思。 报词：壮，粗壮的壮。[词典](https://zdic.net/hans/壮)

- [ ] **洁**：洁是左右结构，左边是三点水，右边是吉。洁有干净的意思。 报词：洁，洁白的洁。[词典](https://zdic.net/hans/洁)

- [ ] **绒**：绒是左右结构，左边是绞丝旁。绒可以指柔软细小的毛。 报词：绒，绒毛的绒。[词典](https://zdic.net/hans/绒)

- [ ] **昂**：昂是上下结构，上边是日。昂首的昂表示抬起，昂首就是抬起头。 报词：昂，昂首的昂。[词典](https://zdic.net/hans/昂)

- [ ] **凤**：凤是半包围结构，里面是又。凤指传说中的一种鸟，凤凰并不是真实存在的鸟。 报词：凤，凤尾竹的凤。[词典](https://zdic.net/hans/凤)

- [ ] **墙**：墙是左右结构，左边是提土旁。墙是用砖、石等建成，用来围住或隔开地方的建筑部分。 报词：墙，墙壁的墙。[词典](https://zdic.net/hans/墙)

- [ ] **晃**：晃是上下结构，上边是日，下边是光。这课的晃读huàng，表示摇动。 报词：晃，摇晃的晃。[词典](https://zdic.net/hans/晃)

### 第2课

- [ ] **轰**：轰是上下结构，上边是车，下边是两个又。轰可以形容很大的声响。 报词：轰，轰响的轰。[词典](https://zdic.net/hans/轰)

- [ ] **湿**：湿是左右结构，左边是三点水。湿表示沾了水或含有较多水分，和干相对。 报词：湿，湿润的湿。[词典](https://zdic.net/hans/湿)

- [ ] **润**：润是左右结构，左边是三点水，右边是闰。润有不干枯的意思，湿润是含有一些水分的样子。 报词：润，湿润的润。[词典](https://zdic.net/hans/润)

- [ ] **笛**：笛是上下结构，上边是竹字头，下边是由。笛子是一种吹奏的乐器。 报词：笛，风笛的笛。[词典](https://zdic.net/hans/笛)

- [ ] **狂**：狂是左右结构，左边是反犬旁，右边是王。狂风的狂表示猛烈，狂风就是很大的风。 报词：狂，狂风的狂。[词典](https://zdic.net/hans/狂)

- [ ] **功**：功是左右结构，左边是工，右边是力。功有成绩、本领等意思，功劳指对事情作出的贡献。 报词：功，功课的功。[词典](https://zdic.net/hans/功)

- [ ] **罚**：罚是上下结构，上边是四字头。罚指对违反规定的人作出处理。 报词：罚，惩罚的罚。[词典](https://zdic.net/hans/罚)

- [ ] **互**：互是独体字，部首是二。互表示彼此，互助就是彼此帮助。 报词：互，互相的互。[词典](https://zdic.net/hans/互)

- [ ] **碰**：碰是左右结构，左边是石，右边是并。碰可以表示物体相撞，也可以表示遇到。 报词：碰，碰撞的碰。[词典](https://zdic.net/hans/碰)

- [ ] **黄**：黄的部首就是黄。黄是一种颜色，成熟的香蕉皮常常是黄色的。 报词：黄，黄色的黄。[词典](https://zdic.net/hans/黄)

- [ ] **急**：急是上下结构，下边是心。急有着急、匆忙的意思，急忙表示行动很赶。 报词：急，急忙的急。[词典](https://zdic.net/hans/急)

- [ ] **荒**：荒是上下结构，上边是草字头。荒野指空旷、少有人去的野外。 报词：荒，荒野的荒。[词典](https://zdic.net/hans/荒)

- [ ] **假**：假左边是单人旁。这课的假读jià，假期指按规定或经批准休息的日子。 报词：假，放假的假。[词典](https://zdic.net/hans/假)

- [ ] **臂**：臂是上下结构，下边是月。臂指从肩到手腕的部分，这课的臂读bì。 报词：臂，双臂的臂。[词典](https://zdic.net/hans/臂)
